## What I'm working on

### [Kairos](https://github.com/Kokosek-Dev/Kairos): an independent Minecraft launcher

A free, open-source (MIT) launcher for Minecraft with signed automatic updates and seven languages.

- **Java and Bedrock** instances side by side in one library
- **Mod detective** that finds the mod behind a crash by switching mods off in halves
- **Texture and skin editors** that show blocks, items and mobs the way the game draws them, in 3D
- **Own in-game mod** (Fabric) for friends, skins and proximity voice chat, in an early version
- Server list with live status for both editions, a play journal and a light theme

Built with Rust, Tauri 2, React and TypeScript. Kairos is not affiliated with Mojang or Microsoft.
